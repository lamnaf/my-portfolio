# Portfolio Website Developer — Labib

Website portfolio modern, responsive, dan tanpa dependency build system.

## Jalankan
Buka `index.html` langsung di browser, atau gunakan Live Server di VS Code.

## Kustomisasi penting
1. Ganti `your@email.com` pada `index.html`.
2. Tambahkan link live project pada masing-masing kartu project jika sudah tersedia.
3. Ganti deskripsi/project sesuai versi final yang ingin ditampilkan.
4. Upload ke GitHub lalu deploy ke Vercel/Netlify.
